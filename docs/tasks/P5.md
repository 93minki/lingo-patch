## 절대 규칙
1. lingo-patch 폴더 안의 파일만 만들고 고친다. 전역 설치 금지.
2. git 쓰기 작업 금지. `docs/` 수정 금지 (단 `docs/tasks/BACKLOG.md`에 새로 발견한 문제를 추가하는 것은 허용).
3. 테스트에서 실제 AI API 호출 금지. 키를 로그에 남기지 않는다.
4. API 키는 background와 옵션 페이지(확장 페이지)에서만 다룬다. content script·팝업으로 키를 보내지 않는다 (팝업에는 "설정됨/안 됨"만).
5. 원본 페이지를 건드리지 않는다는 P4 규칙 유지. 진행 표시는 Shadow DOM 안에서만 그린다.
6. UI 문구는 한국어. 나중에 다국어로 바꿀 수 있게 `src/ui/strings.ts` 한 곳에 모은다.

## 1. 진행 중 요청 완주 (큐 정책 변경)
- 탭 이동·닫기·SPA 이동(`reset`)·Port 끊김 시: **아직 보내지 않은 항목만 취소**한다. **이미 API로 보낸 배치는 중단하지 않고** 응답을 받아 캐시에 저장한다 (전달할 탭이 없어도 저장)
- `cancelTab`에서 진행 중 배치를 abort하던 동작 제거. 사용자가 확장을 끄거나 설정(제공자)을 바꿔 큐를 새로 만들 때만 abort 허용
- 테스트: 진행 중 배치가 있는 탭을 취소 → 배치 완료 후 결과가 저장 콜백으로 전달됨, 대기 항목은 요청되지 않음

## 2. 진행 표시 (content, 화면 상단 가운데)
- `position: fixed; top: 12px; left: 50%; transform: translateX(-50%)`, 최상위 z-index, Shadow DOM 호스트 1개
- **페이지 조작을 막지 않는다:** 호스트와 알약 모양 표시 모두 `pointer-events: none`. 예외는 오류 상태의 "설정 열기" 링크 하나(그 요소만 `pointer-events: auto`)
- 상태
  - 번역 중: `번역 중 · 12 / 40` (이 페이지에서 요청한 문단 기준, 완료 수 / 요청 수). 0.3초 안에 끝나는 경우는 표시하지 않음(깜빡임 방지)
  - 완료: `번역 완료` 1.5초 표시 후 서서히 사라짐
  - 오류: `auth` → "API 키를 확인하세요 · 설정 열기", `rate_limit` → "요청 한도 초과 · 잠시 후 다시 시도합니다", 그 외 → "일부 문단을 번역하지 못했습니다". 설정 미지정 → "번역 설정이 필요합니다 · 설정 열기"
  - 캐시에서만 복원한 경우(요청 0개)에는 표시하지 않음
- 라이트/다크 대응 (`prefers-color-scheme`), 작고 반투명한 알약 모양, 페이지 글꼴과 무관한 시스템 글꼴
- 화면 위에 다른 고정 요소(헤더)와 겹쳐도 클릭은 그대로 통과해야 함
- "설정 열기"는 background에 메시지 → `runtime.openOptionsPage()`

## 3. 확장 아이콘 배지
- 탭별로 남은(요청했지만 완료되지 않은) 문단 수를 `action.setBadgeText`로 표시, 0이면 지움. 오류가 있으면 `!`

## 4. 팝업 (`entrypoints/popup`)
- 현재 탭 hostname 표시
- **이 사이트 항상 번역** 토글 (`autoSites` 추가/제거, 즉시 반영)
- **지금 번역 / 번역 끄기** 버튼 (`toggle`과 동일)
- **표시 모드** 3개 선택 (이중 언어 / 번역문만 / 원문만)
- **이 페이지 다시 번역**: 현재 페이지에서 찾은 세그먼트 키들을 캐시에서 삭제 → 다시 요청. 확인 한 번 묻기 ("이 페이지의 번역 N개를 다시 요청합니다")
  - `CacheDb.deleteMany(keys)` 추가
- 통계: 이 페이지 문단 수 / 캐시 복원 수 / 새로 번역한 수 / 남은 수
- 번역 설정이 없으면 위 기능 대신 "번역 설정하기" 버튼(옵션 페이지 열기)
- 내부 페이지(`chrome://`, 확장 스토어 등)에서는 "이 페이지는 번역할 수 없습니다"

## 5. 옵션 페이지 (`entrypoints/options`)
- **첫 실행 안내** (provider가 null일 때 맨 위, DESIGN §8.5)
  - "무료로 시작": Gemini(기본 추천) 키 발급 단계 3줄 + 링크, 대안 Groq·OpenRouter 링크. 무료 등급은 입력이 서비스 개선에 쓰일 수 있다는 안내 한 줄
  - "더 좋은 품질": OpenAI, Anthropic, DeepSeek
  - 링크 URL은 공식 키 발급 페이지를 문서로 확인해서 사용 (보고서에 기재)
- **번역 엔진**: 제공자 선택(OpenAI, Anthropic, Gemini, DeepSeek, Groq, OpenRouter, 직접 입력(OpenAI 호환)) → API 키 입력(`type=password`, 보기 토글) → **키 확인** 버튼(background가 `listModels` 실행) → 모델 선택
  - 모델 목록: 일반 제공자는 `selectModelOptions` 결과, 프리셋은 `listModels` 결과 전체(OpenRouter는 `:free` 표시, "무료만 보기" 필터), 직접 입력은 base URL + 모델 ID 텍스트 입력
  - 직접 입력의 base URL은 저장 시 `permissions.request`로 해당 origin 권한 요청 (거절되면 저장 안 함)
  - 키 확인 실패 시 이유 표시(키 오류 / 네트워크 / 기타)
  - 안내 문구: "API 키는 이 브라우저에만 저장되고 선택한 AI 제공자로만 전송됩니다"
- **번역**: 목표 언어(한국어 기본, 영어·일본어·중국어(간체) 정도 선택지), 기본 표시 모드
- **자동 번역 사이트**: 목록, 삭제, 추가(hostname 입력)
- **캐시**: 사용량(문단 수, MB, 상한 대비 %), 보관 기간(일)·용량 상한(MB) 변경, 사이트별 삭제, 전체 삭제(확인)
- **단축키**: 현재 할당된 단축키 표시(`commands.getAll`) + 브라우저 단축키 설정 페이지 안내 (Chrome 계열: `chrome://extensions/shortcuts`)
- 설치 직후(`runtime.onInstalled`, reason=install) provider가 없으면 옵션 페이지 자동 열기

## 6. background API (팝업·옵션용)
- `runtime.sendMessage` 요청/응답 메시지 (타입 정의는 `src/messaging/`):
  `getTabStatus(tabId)`, `toggleTab(tabId)`, `retranslatePage(tabId)`, `validateProvider(cfg)` → `{ ok, models? , error? }`, `cacheUsage()`, `clearCache()`, `deleteSiteCache(origin)`, `openOptions()`
- 팝업·옵션은 설정 변경을 `updateSettings`로 직접 저장해도 되지만, 키 확인·캐시 조작은 background를 거친다

## E2E 추가 (기존 시나리오 유지)
1. 모의 API에 지연(예: 2초)을 넣고 번역 중 → 진행 표시가 상단 가운데에 보임, 그 아래 위치 페이지 요소 클릭이 정상 동작(`elementFromPoint`가 페이지 요소를 반환)
2. 번역 요청이 진행 중일 때 B로 이동 → 지연 후 A로 복귀: 진행 중이던 배치 항목은 **추가 호출 없이** 복원, 보내지 않았던 항목만 새로 요청
3. 다시 번역: 실행 후 해당 페이지 세그먼트 수만큼 새 요청 발생
4. 일반 빌드 매니페스트 검사 유지
