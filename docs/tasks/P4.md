# P4 지시서 — 페이지 렌더링 + 캐시 복원 (핵심 단계)

발신: Opus (w6:p1) → 수신: Codex (w6:p2), Codex가 일부를 Cursor (w6:p3)에 위임

## 먼저 읽을 것
- `AGENTS.md`
- `docs/DESIGN.md` §1 목표, §4 아키텍처, §5.3 삽입 방식, §6 캐시, §7.6 프리셋·속도 제한(이번에 추가), §8.3 단축키, §13 위험
- 이미 있는 코드: `src/core/segment`, `src/core/cache`, `src/storage/cache-db.ts`, `src/core/queue`, `src/providers`

## 절대 규칙
1. lingo-patch 폴더 안의 파일만 만들고 고친다. 전역 설치 금지. (Playwright 브라우저 바이너리 설치는 `npx playwright install chromium`으로 허용 — 기본 캐시 위치 사용 가능)
2. git 쓰기 작업 금지. `docs/` 수정 금지.
3. 테스트에서 실제 AI API 호출 금지. API 키를 코드·로그에 남기지 않는다.
4. **원본 페이지의 텍스트 노드와 기존 요소의 속성·스타일을 수정하지 않는다.** 허용: `<lp-t>` 삽입, 블록 요소에 `data-lp-*` 속성 추가, `<html>`에 `data-lp-mode` 속성 추가, `<style id="lp-style">` 1개 삽입.
5. API 키는 background에만 있다. content script로 키나 제공자 설정을 보내지 않는다.

## 목표 (완료 판정 기준)
**문서 페이지 A를 번역 → 페이지 B로 이동 → A로 돌아오면, A는 AI 호출 0회로 번역이 즉시 복원된다.** 새로고침, 브라우저 재시작 뒤에도 같다.

## 분배

### Cursor 담당 (각각 독립, Codex가 순서대로 위임하고 검토)
- C1. `src/storage/settings.ts`: 설정 스키마 + 읽기/쓰기/변경 구독 (`browser.storage.local`, 키 `lp-settings`)
  ```ts
  export interface Settings {
    provider: ProviderConfig | null;      // null이면 번역 불가 상태
    preset?: PresetId;                    // 'deepseek' | 'groq' | 'openrouter'
    targetLang: string;                   // 기본 'ko'
    autoSites: string[];                  // 항상 번역할 hostname 목록
    displayMode: 'bilingual' | 'translation' | 'original';  // 기본 'bilingual'
    cache: { ttlDays: number; maxMB: number };              // 기본 90, 20
  }
  export function getSettings(): Promise<Settings>;          // 저장값 + 기본값 병합, 손상된 값은 기본값
  export function updateSettings(patch: Partial<Settings>): Promise<Settings>;
  export function onSettingsChanged(cb: (s: Settings) => void): () => void;
  ```
  - background의 `lp-evict` 알람이 상수 대신 `settings.cache`를 쓰도록 수정
- C2. `src/providers/presets.ts`: DESIGN §7.6 프리셋 3종 `{ id, label, baseUrl, free: 'yes'|'no'|'free-models-only', rpm, signupUrl, docsUrl }`. base URL·기본 RPM은 **공식 문서로 확인**(확인 URL 보고). OpenRouter는 `listModels` 결과에서 `:free`로 끝나는 모델을 무료로 표시하는 헬퍼 포함. 세 도메인을 매니페스트 `host_permissions`에 추가
- C3. 큐 속도 제한: `TranslateQueue`에 `maxRequestsPerMinute?: number` 옵션 (슬라이딩 윈도 60초, 한도에 도달하면 다음 배치를 대기시킴, 가짜 타이머 테스트 포함). 기본값 없음(무제한). Gemini 무료 등급 기본 RPM도 공식 문서로 확인해 프리셋 표와 함께 보고
- C4. `src/content/style.ts`: `<style id="lp-style">` 내용 (DESIGN §5.3)
  - `lp-t` 기본: 부모 글꼴 상속, `opacity: .85`. `lp-t[data-lp-display="block"]`: `display:block; margin-top:.25em`. `[data-lp-display="inline"]`: `display:inline; margin-left:.4em`
  - `html[data-lp-mode="original"] lp-t { display:none !important }`
  - `html[data-lp-mode="translation"] [data-lp-src-hidden]`: `font-size:0` 방식으로 원문 숨김, 그 안의 `lp-t`는 글꼴 크기 복원(`font-size: var(--lp-fs)` — 렌더러가 블록의 원래 font-size를 `--lp-fs`로 `lp-t`에 인라인 지정)
  - `lp-t[data-lp-state="error"]`: 작은 ⚠ 표시, `lp-t[data-lp-state="pending"]`: 아무것도 표시하지 않음(레이아웃 흔들림 방지)

### Codex 담당
- X1. **메시징** `src/messaging/`: content ↔ background는 탭마다 장기 연결 Port(`lp-page`) 하나. 메시지 타입을 discriminated union으로 정의
  - content → bg: `lookup {keys[]}`, `translate {items: {key, markup, priority}[] , context}`, `page {pageId, keys[]}`, `reset` (URL 변경)
  - bg → content: `cached {entries: {key, text}[]}`, `translated {key, text}`, `failed {key, kind}`, `mode {displayMode}`, `toggle`
  - Port가 끊기면 bg는 그 탭의 큐 대기분을 `cancelTab`
- X2. **background 번역 서비스**: 설정에서 provider 생성(설정 변경 시 재생성), `TranslateQueue` 하나(RPM은 프리셋 값), 번역 성공 시 `cacheDb.putMany` 후 content로 전송, 실패는 `failed`. `lookup`은 `getMany`. `page`는 `putPage`. 같은 key를 여러 탭이 요청해도 API는 1회
- X3. **content 파이프라인** (`src/content/` + `entrypoints/content/index.ts`)
  1. 시작 조건: `settings.autoSites`에 현재 hostname이 있거나, `toggle` 메시지를 받았을 때. 다시 `toggle`하면 번역 끄기(`lp-t` 전부 제거, 관찰 중지)
  2. `findSegments(document.body, { targetLang })` → 각 세그먼트 `makeCacheKey` (glossary는 빈 배열, P6에서 연결)
  3. `pages`의 이전 키 목록이 있으면 먼저 `lookup`(prefetch), 이어서 현재 키 전부 `lookup` → 캐시 적중분 **즉시 렌더**
  4. 캐시에 없는 세그먼트는 `IntersectionObserver`(rootMargin: 위아래 1화면)로 화면 근처에 온 것만 `translate` 요청 (화면 밖은 스크롤해서 다가올 때 요청 — 토큰 절약). 보이는 것 priority 2, 근처 1
  5. 렌더: `deserialize(text, placeholders, document)` → `<lp-t data-lp-key>`에 넣어 `anchor` 앞(없으면 블록 끝)에 삽입. 블록의 `getComputedStyle` display가 block/list-item/table-cell/flex(column) 계열이면 `block`, 그 외 `inline`. 같은 key가 이미 그 자리에 있으면 다시 넣지 않음
  6. `MutationObserver`: (a) 우리가 넣은 `lp-t`가 지워졌는데 블록은 남아 있으면 메모리 Map에서 다시 삽입(네트워크 없음) (b) 새 내용이 추가되면 300ms 디바운스 후 2~5 반복 (이미 처리한 세그먼트는 건너뜀). 우리 자신의 삽입으로 생긴 변경은 무시. 같은 블록이 5초 안에 3번 넘게 지워지면 그 블록은 포기하고 콘솔 경고 1회
  7. SPA: `navigation` API가 있으면 `navigatesuccess`, 없으면 `popstate` + 500ms 간격 `location.href` 확인. URL이 바뀌면 `reset` 전송 후 2단계부터 다시
  8. 표시 모드: `<html data-lp-mode>` 설정, `mode` 메시지와 설정 변경에 반응
- X4. **단축키** (`commands`): `toggle-translate` = `Alt+A`, `cycle-mode` = `Alt+S`. background가 받아 활성 탭 content로 `toggle` / 모드 순환 후 설정 저장
- X5. **E2E** (Playwright + Chromium, 확장 로드)
  - 로컬 HTTP 서버가 `tests/fixtures`의 HTML을 서빙 (A = `react-learn.html`, B = `mdn-array-map.html`), 같은 서버가 **OpenAI 호환 모의 API**(`/v1/chat/completions`)도 제공하고 호출 횟수를 센다. 모의 응답은 각 item의 text 앞에 `[KO] `를 붙여 그대로 돌려준다(자리표시 유지)
  - E2E 전용 빌드 모드에서만 `http://127.0.0.1/*` host 권한과 테스트 설정 주입을 허용 (일반 빌드 매니페스트에는 없어야 함 — 확인 단언 포함)
  - 시나리오
    1. A 열기 + 번역 → `lp-t`가 생기고 내용이 `[KO]`로 시작, 원문 텍스트 노드 불변(번역 전후 `body.innerText`에서 `lp-t` 제외한 텍스트 동일)
    2. B로 이동 → A로 돌아오기: **추가 API 호출 0회**, `lp-t` 다시 존재
    3. A 새로고침: 추가 호출 0회
    4. 브라우저 컨텍스트 종료 후 같은 프로필로 재시작 → A: 추가 호출 0회
    5. `<pre>` 안에 `lp-t` 없음
    6. `Alt+S` 순환으로 `data-lp-mode`가 바뀜
    7. A에서 스크롤하지 않으면 화면 밖 세그먼트는 요청되지 않음(요청된 항목 수 < 전체 세그먼트 수)
  - `npm run test:e2e` 스크립트. 헤드리스로 동작해야 함
