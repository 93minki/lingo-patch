## 1. 용어집
- 저장: `browser.storage.local`의 `lp-glossary` = `{ global: GlossaryEntry[], sites: Record<hostname, GlossaryEntry[]> }`. 같은 term은 사이트 항목이 전역을 덮어씀
- 기본 제공 목록(`src/core/glossary/defaults.ts`): 개발 문서에서 영어로 두는 게 자연스러운 용어 `keep` 20개 안팎 (props, state, hook, callback, component, middleware, render, prop drilling 같은 것 — 사용자가 끄거나 지울 수 있게 "기본 용어집 사용" 토글)
- content: 유효 용어집(전역+사이트+기본)을 background에서 받아 `makeCacheKey`에 넘긴다 (용어집은 비밀이 아니므로 `mode` 메시지 등에 포함 가능). 용어집이 바뀌면 그 용어가 들어간 세그먼트만 키가 달라져 다시 번역된다 (나머지는 캐시 유지) — 화면은 바뀐 세그먼트만 갱신
- background: 배치 요청에 그 배치 항목들에 등장하는 용어만 골라 프롬프트에 넣는다 (`glossaryFingerprint`와 같은 매칭 규칙 재사용)
- UI(옵션 고급 설정): 전역 용어집 표(용어, 방식 keep/map, 번역어, 대소문자 구분, 삭제), 추가 폼, 사이트별 용어집(hostname 선택 후 같은 표), 기본 용어집 토글. 팝업 설정 화면에는 "용어집 관리" 링크만
- 테스트: 사이트 우선 병합, 용어 변경 시 해당 세그먼트 키만 변경, 프롬프트에 등장 용어만 포함, 기본 목록 토글

## 2. 선택/호버 번역
- **호버**: 수정키(기본 Alt/Option, 설정에서 Alt·Control·Shift·끄기)를 누른 채 문단에 마우스를 올리면 그 블록만 번역해 일반 번역과 같은 방식(`lp-t`)으로 붙인다. 페이지 번역이 꺼져 있어도 동작. 다시 같은 키+호버하면 그 블록 번역 제거(토글)
- **선택**: 텍스트를 드래그해 놓으면 선택 끝 근처에 작은 번역 버튼(Shadow DOM) → 누르면 팝오버에 번역 표시. 바깥 클릭·Esc로 닫힘. 입력칸·contenteditable 안에서는 표시하지 않음. 설정에서 끄기 가능. 선택 텍스트는 평문으로 번역(자리표시 없음), 최대 2,000자
- 두 기능 모두 같은 캐시·큐를 쓴다 (선택 번역 키는 평문을 이스케이프한 markup으로 `makeCacheKey`)
- 버튼·팝오버 외에는 `pointer-events: none` 원칙 유지, 페이지 조작 방해 금지. 다크 모드 대응
- 테스트: 수정키 없이 호버하면 아무 일 없음, 수정키+호버 시 해당 블록만 요청, 선택 버튼 표시/숨김 조건, 팝오버 닫힘, 입력칸 제외

## 3. 캐시 내보내기·가져오기 (DESIGN §6.4)
- 옵션 캐시 섹션에 "내보내기" / "가져오기" 버튼
- 형식: `lingo-patch-cache-YYYYMMDD.jsonl.gz` (`CompressionStream('gzip')`, 미지원이면 `.jsonl`). 첫 줄 헤더 `{ format: 1, promptVersion, exportedAt, count }`, 이후 한 줄에 `{ key, translated, srcLang?, model, provider, createdAt }`
- 가져오기 검증 (신뢰할 수 없는 입력):
  - 파일 크기 50MB 초과 거절, gzip/평문 자동 판별
  - 헤더 `format === 1` 아니면 거절, `promptVersion`이 다르면 경고만 표시하고 계속(사용자 확인)
  - 각 줄: key는 32자 hex, translated는 문자열 20,000자 이하, createdAt은 유한 숫자 — 어긋나면 그 줄만 건너뛰고 개수 보고
  - 같은 키가 이미 있으면 `createdAt`이 더 최신인 쪽 유지
  - 가져온 번역문은 렌더 시 기존과 같이 `deserialize`(텍스트 토큰화, innerHTML 금지)를 거치므로 HTML 주입이 불가능해야 한다 — 이를 확인하는 테스트 포함
  - 가져오기 후 용량 상한 초과 시 기존 정리 정책 실행
- 결과 표시: 가져온 수 / 건너뛴 수 / 기존이 더 최신이라 유지한 수
- 큰 파일에서 UI가 멈추지 않게 스트림·배치(예: 500줄 단위 트랜잭션)
- 테스트: 왕복(내보내기→비우기→가져오기→동일), 손상 줄 건너뛰기, 잘못된 헤더 거절, 최신 우선 병합, 악성 translated(`<img onerror>` 등)가 텍스트로만 렌더
