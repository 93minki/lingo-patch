## 분배

### Cursor 담당 (Codex가 herdr로 위임)
위임 방법:
```
herdr agent prompt w6:p3 "<지시>" --wait --timeout 900000
herdr agent read w6:p3 | tail -60
```
지시에는 이 파일의 '절대 규칙'을 그대로 포함할 것. 지시는 번호 매긴 단계로 짧게 쓴다.

- C1. WXT 프로젝트 생성 (비대화형): vanilla TypeScript 템플릿, npm 사용. `srcDir: 'src'`로 설정하고 엔트리포인트를 `src/entrypoints/`로 옮긴다
- C2. `AGENTS.md` 초안 작성: 프로젝트 한 줄 소개, 디렉터리 구조(§10), 명령어 목록, 규칙(커밋 금지, 폴더 밖 수정 금지, `src/core/`는 DOM/브라우저 API에 의존하지 않음, 원본 페이지 텍스트 노드 수정 금지, 새 코드는 단위 테스트 포함)

### Codex 담당
- X1. Cursor의 C1·C2 결과 검토 및 수정
- X2. 검사 도구 설정
  - TypeScript strict (`noUncheckedIndexedAccess` 포함)
  - ESLint flat config + typescript-eslint, Prettier (ESLint와 충돌 없도록)
  - Vitest + happy-dom, `fake-indexeddb`는 설치만 (P2에서 사용)
  - Playwright는 P4에서 설정 (지금은 하지 않음)
- X3. `package.json` 스크립트: `dev`, `dev:firefox`, `build`, `build:firefox`, `zip`, `typecheck`, `lint`, `format`, `test`
- X4. 엔트리포인트 4종 최소 구현
  - `background.ts`: 설치 시 로그 1줄
  - `content/index.ts`: `matches: ['<all_urls>']`, `runAt: 'document_idle'`, 아무 것도 하지 않는 초기화 함수
  - `popup/`, `options/`: Preact로 "lingo-patch" 제목만 표시 (`@preact/preset-vite` 또는 WXT 권장 방식)
- X5. §10 구조대로 빈 디렉터리 생성 (`src/core/{segment,cache,queue,glossary,prompt}`, `src/providers`, `src/storage`, `src/content`, `src/messaging`, `src/platform`, `src/ui`, `site-rules`, `tests/{unit,fixtures,e2e}`). 빈 폴더는 `.gitkeep`
- X6. 매니페스트: 이름 `lingo-patch`, 권한 `storage`, `alarms`, Firefox용 `browser_specific_settings.gecko.id = "lingo-patch@local"`. host_permissions는 아직 넣지 않음
- X7. 샘플 단위 테스트 1개 (`tests/unit/smoke.test.ts`)로 Vitest 동작 확인
- X8. `.gitignore` (node_modules, .output, .wxt, 빌드 산출물)
