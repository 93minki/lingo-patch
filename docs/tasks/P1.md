## API (파일 분리는 Codex 재량, `src/core/segment/index.ts`에서 export)

```ts
export interface SegmentRules {
  include?: string[];   // 추가로 블록으로 취급할 CSS 선택자
  exclude?: string[];   // 추가로 제외할 CSS 선택자 (자기 자신과 자손 모두 제외)
}

export interface Placeholder {
  id: number;               // N
  kind: 'atomic' | 'paired';
  node: Element;            // 원본 요소 참조 (복원 시 복제 원본)
}

export interface Segment {
  block: Element;           // 번역 단위 블록
  anchor: Node | null;      // 번역문을 이 노드 앞에 삽입 (null이면 block 끝에 append)
  markup: string;           // 자리표시 직렬화 결과, 정규화됨
  text: string;             // 태그 없는 평문 (언어 감지·길이 판단용)
  placeholders: Placeholder[];
}

export function findSegments(root: Element, opts?: { rules?: SegmentRules; targetLang?: string }): Segment[];
export function serializeInline(nodes: Node[]): { markup: string; text: string; placeholders: Placeholder[] };
export function deserialize(markup: string, placeholders: Placeholder[], doc: Document):
  { fragment: DocumentFragment; fallback: boolean };
export function normalizeMarkup(markup: string): string;   // 연속 공백 → 한 칸, 앞뒤 trim
export function isLikelyLang(text: string, lang: string): boolean; // 'ko'만 우선 지원: 한글 비율 > 0.5
```

## 동작 명세

### 블록 찾기 (`findSegments`)
1. `TreeWalker`로 `root`를 순회 (`root.ownerDocument` 사용, 전역 `document` 금지)
2. **제외**(자기와 자손 전부): `pre, script, style, noscript, textarea, select, svg, math, template, iframe, [contenteditable=""], [contenteditable="true"], [translate="no"], .notranslate, [aria-hidden="true"], [hidden], lp-t, [data-lp-ignore]` + `rules.exclude`
   - `code`는 `pre` 밖에서 인라인으로 쓰이면 원자 자리표시, 블록 자체가 `code`뿐이면 제외
3. **블록 후보**: `p, li, h1–h6, td, th, dt, dd, blockquote, figcaption, summary, caption, label, legend` + `rules.include` + 공백이 아닌 텍스트를 **직접 자식으로** 가진 `div`/`section`/`article`/`span`(블록 성격 요소 안에 있지 않은 경우)
4. **중첩 처리**: 블록 후보 안에 다른 블록 후보가 있으면 안쪽 것을 각각 세그먼트로 만든다. 바깥 블록은 **블록 자식 사이의 인라인 내용 덩어리**만 세그먼트로 만든다
   - 예: `<li>Item text <ul><li>child</li></ul></li>` → 세그먼트 2개: `"Item text"`(block=바깥 li, anchor=`<ul>`), `"child"`(block=안쪽 li, anchor=null)
   - 한 블록에 인라인 덩어리가 여러 개면 덩어리마다 세그먼트 (anchor = 다음 블록 자식)
5. **건너뜀**: `text`가 공백 제거 후 2글자 미만, 숫자·기호·공백만 있는 경우, `targetLang`이 주어지고 `isLikelyLang(text, targetLang)`이 참인 경우
6. 결과는 문서 순서. 같은 노드가 두 세그먼트에 들어가면 안 된다

### 직렬화 (`serializeInline`)
- 텍스트 노드: `& < >`를 `&amp; &lt; &gt;`로 이스케이프해서 이어 붙인다
- 원자 요소(§5.2 목록 + 알 수 없는 요소 + 내부에 블록 요소가 있는 인라인 요소): `<xN/>`, `text`에는 요소의 textContent를 그대로 넣는다
- 쌍 요소(§5.2 목록): `<gN>` + 자식 재귀 직렬화 + `</gN>`
- N은 세그먼트 안에서 0부터, 등장 순서(여는 태그 기준)대로
- 주석 노드 무시. 결과 markup은 `normalizeMarkup` 적용

### 복원 (`deserialize`)
- 문자열을 직접 토큰화한다 (`innerHTML`/`DOMParser` 사용 금지 — LLM 응답을 HTML로 해석하지 않기 위함)
  - 토큰: 텍스트, `<xN/>`, `<gN>`, `</gN>`, 엔티티 `&amp; &lt; &gt; &quot; &#39;`
  - 그 밖의 `<…>`는 일반 텍스트로 취급
- 원자: `placeholders[N].node.cloneNode(true)`, 쌍: `cloneNode(false)` 후 자식 채움
- **fallback**: 다음 중 하나면 태그를 모두 버리고 텍스트 노드 하나로 만든 fragment, `fallback: true`
  - 응답의 자리표시 id 집합 ≠ 원본 집합 (누락, 추가, 중복 모두)
  - 종류 불일치 (`x`↔`g`), 닫히지 않음, 잘못된 중첩
- 원본 노드는 절대 이동·수정하지 않는다 (복제만)

## 필수 단위 테스트 케이스
1. 인라인 code + 링크: 설계 문서 §5.2 예시와 정확히 같은 markup
2. `<pre><code>` 블록은 세그먼트 없음, `pre` 밖 인라인 `code`는 `<xN/>`
3. 중첩 리스트: 위 4번 예시대로 세그먼트 2개, anchor 확인
4. `translate="no"`, `.notranslate`, `[hidden]`, `aria-hidden`, `lp-t` 내부는 제외
5. 한국어 문단은 `targetLang: 'ko'`일 때 건너뜀, 영어는 포함
6. 숫자만 / 기호만 / 1글자 텍스트는 건너뜀
7. 텍스트의 `<`, `&` 이스케이프 → 복원 시 원래 문자
8. 왕복: `deserialize(markup)`이 원본과 같은 textContent·같은 요소 구조(태그명, href)를 만듦
9. 자리표시 순서가 바뀐 번역(`<g1>…</g1>에서 <x0/>`) 정상 복원, `fallback: false`
10. 자리표시 누락 / 중복 / 잘못된 중첩 / 미지의 태그 `<script>` → `fallback: true`이고 `<script>`는 텍스트로만 존재
11. `rules.include`/`rules.exclude` 동작
12. 블록 안에 블록 성격 자식이 있는 인라인 요소(`<span><div>…</div></span>`) 처리 — 크래시 없고 노드 중복 없음

## Fixture 테스트 (`tests/unit/segment/fixtures.test.ts`)
- 각 fixture를 happy-dom에 로드해 `findSegments(document.body)` 실행
- 단언: 세그먼트 수 > 20, 어떤 세그먼트의 block도 `pre` 안에 있지 않음, 같은 노드가 두 세그먼트에 들어가지 않음, 모든 세그먼트가 `deserialize(markup)` 왕복 시 `fallback: false`
- 실행 시간: fixture 하나당 `findSegments`가 200ms 이하 (happy-dom 기준, 느리면 보고)
- 사이트별 세그먼트 수와 처음 5개 markup을 보고서에 적는다 (스냅샷 파일은 만들지 않음)
