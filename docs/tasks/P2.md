발신: Opus (w6:p1) → 수신: Codex (w6:p2), Codex가 일부를 Cursor (w6:p3)에 위임

## 먼저 읽을 것
- `AGENTS.md`
- `docs/DESIGN.md` §6 캐시 설계 전체 (키, 스키마, 정리, 기본값 TTL 90일 / 20MB)

## 절대 규칙
1. lingo-patch 폴더 안의 파일만 만들고 고친다. 전역 설치 금지.
2. git 쓰기 작업 금지.
3. `docs/DESIGN.md`, `docs/tasks/` 수정 금지. 설계와 다르게 해야 하면 보고서에 이유를 적는다.
4. 런타임 의존성은 `idb` 하나만 추가 허용.
5. `src/core/`의 전역 객체 금지 규칙 예외: 표준 Web Crypto(`globalThis.crypto.subtle`)는 사용 가능 (브라우저·Node 모두 표준).

## 목표
번역 결과를 문단 단위로 저장·조회·정리하는 캐시 계층을 만든다. 번역 API 호출, 페이지 렌더링, 옵션 UI는 하지 않는다.

### Codex 담당
- X1. `src/core/cache/policy.ts` (순수 함수)
  ```ts
  export const DEFAULT_TTL_DAYS = 90;
  export const DEFAULT_MAX_BYTES = 20 * 1024 * 1024;
  export const TOUCH_INTERVAL_MS = 24 * 60 * 60 * 1000;
  export interface EntryMeta { key: string; lastAccess: number; bytes: number }
  // TTL 지난 항목 + (남은 총량 > maxBytes면 lastAccess 오래된 순으로 maxBytes의 90%까지) 삭제할 키
  export function selectEvictions(entries: EntryMeta[], now: number, opts: { ttlMs: number; maxBytes: number }): string[];
  export function estimateBytes(key: string, translated: string): number; // (key.length + translated.length) * 2 + 64
  export function shouldTouch(lastAccess: number, now: number): boolean;
  ```
- X2. `src/storage/cache-db.ts` — `idb` 기반, DB 이름 기본 `lingo-patch`, 테스트용으로 이름 주입 가능
  - 스키마 v1: DESIGN §6.2 그대로 (`segments` + `lastAccess` 인덱스, `pages` + `updatedAt` 인덱스, `meta`)
  ```ts
  export interface CachedSegment { translated: string; srcLang?: string; model: string; provider: string;
    createdAt: number; lastAccess: number; bytes: number }
  export interface CacheDb {
    getMany(keys: string[], now?: number): Promise<Map<string, CachedSegment>>; // 조회한 항목은 shouldTouch면 lastAccess 갱신 (한 트랜잭션)
    putMany(entries: { key: string; value: Omit<CachedSegment, 'createdAt' | 'lastAccess' | 'bytes'> }[], now?: number): Promise<void>;
    getPage(pageId: string): Promise<string[] | undefined>;   // pageId = origin + pathname
    putPage(pageId: string, keys: string[], now?: number): Promise<void>;
    evict(now: number, opts: { ttlMs: number; maxBytes: number }): Promise<{ deleted: number; bytesAfter: number }>;
    usage(): Promise<{ count: number; bytes: number }>;
    deleteSite(origin: string): Promise<number>; // 그 origin의 pages가 참조하는 키 중 다른 origin pages가 참조하지 않는 키만 삭제 + 해당 pages 삭제
    clear(): Promise<void>;
    close(): void;
  }
  export function openCacheDb(name?: string): Promise<CacheDb>;
  ```
  - 총 용량은 `meta`에 누적값으로 관리하지 말고 `usage()`에서 커서로 합산 (정확성 우선, 20MB 규모라 충분)
  - `evict`: `lastAccess` 인덱스 커서로 메타만 모아 `selectEvictions` 호출 → 삭제. TTL이 지난 `pages`도 삭제
- X3. `src/entrypoints/background.ts`: `alarms`로 `lp-evict` 알람을 하루 1회 등록(설치·시작 시, 이미 있으면 재등록하지 않음), 알람 시 기본값으로 `evict` 실행
- X4. 테스트 `tests/unit/cache/{policy,cache-db}.test.ts` — `fake-indexeddb` 사용, 테스트마다 다른 DB 이름
  - policy: TTL 경계값, 용량 초과 시 오래된 순 삭제·90%까지, 둘 다 해당 없으면 빈 배열
