# P5 추가 — 팝업 안 설정 화면

발신: Opus (w6:p1) → 수신: Codex (w6:p2, GPT-6.1 Terra high), 화면 작업은 Cursor (w6:p3)에 위임

## 배경
팝업의 "설정"을 누르면 옵션 페이지가 새 탭으로 열려 보던 페이지를 떠나게 된다. 사용자는 보던 페이지에서 바로 설정하길 원한다. 결정: **팝업 안에서 설정 화면으로 전환**한다. 페이지 위 오버레이는 API 키를 웹페이지 문맥에서 입력하게 되므로 금지.

## 절대 규칙
lingo-patch 폴더 안만 수정, 전역 설치 금지, git 쓰기 금지, `docs/` 수정 금지(BACKLOG 추가만 허용), 실제 AI API 호출 금지. API 키는 팝업(확장 페이지)과 background에서만 다룬다.

## 요구사항
1. 팝업에 두 화면: **메인**(지금 화면) ↔ **설정**. 메인 아래 "설정" 버튼을 누르면 같은 팝업 안에서 설정 화면으로 바뀐다. 설정 화면 맨 위에 "← 뒤로"
2. 설정 화면 항목 (옵션 페이지의 해당 컴포넌트를 **재사용**하도록 분리 — 같은 로직을 두 번 쓰지 말 것)
   - 번역 엔진(제공자·프리셋 선택), API 키(가림/보기), 키 확인, 모델 선택, 저장
   - 목표 언어, 표시 모드
   - 맨 아래 "고급 설정 (자동 번역 사이트, 캐시, 단축키)" 링크 → 옵션 페이지 열기
3. 번역 설정이 없을 때 메인 화면의 "번역 설정하기" 버튼도 옵션 페이지가 아니라 **팝업 설정 화면**으로 전환한다. 설정 화면 위쪽에 무료 키 안내를 짧게(Gemini 발급 링크 + "다른 무료 선택지는 고급 설정에서") 표시
4. **OpenAI 호환 직접 입력**은 권한 요청 창 때문에 팝업이 닫힐 수 있으므로, 팝업에서는 선택 시 "고급 설정에서 설정하세요" 안내와 옵션 페이지 링크만 보여준다
5. 팝업 너비 340px 유지, 설정 화면은 세로 스크롤 허용(최대 높이 560px 정도), 다크 모드 대응 (현재 팝업 스타일과 일관)
6. 저장 후 메인 화면으로 돌아가고, 현재 탭에 설정 변경이 바로 반영돼야 한다 (기존 `onSettingsChanged` 흐름)

## 분배
- Cursor: 옵션 페이지 엔진·번역 섹션을 재사용 가능한 컴포넌트로 분리, 팝업 화면 전환 UI·스타일, 문구(`strings.ts`)
- Codex: 분리 구조 설계·검토, 팝업에서의 키 확인·저장 흐름 연결, 테스트·E2E 확인

## 테스트
- 단위: 메인↔설정 전환, 설정 없음 → 설정 화면, 키 확인 성공/실패 표시, 저장 후 메인 복귀, 직접 입력 선택 시 안내만 표시
- E2E: 기존 시나리오 유지 (팝업 E2E가 있다면 설정 화면 전환 1개 추가)

## 추가 요구사항 (사용자 피드백, 같은 작업에서 처리)

### A. 다크 모드 가독성
현상: 다크 모드에서 옵션 페이지(브라우저가 띄우는 옵션 창)의 숫자 입력칸(보관 기간 90, 용량 상한 20)과 일부 입력칸 글자가 배경과 같은 색이라 보이지 않는다. 비활성 버튼(추가, 사이트별 삭제)도 거의 보이지 않는다.
- 옵션 페이지·팝업 모두 `:root { color-scheme: light dark; }`를 선언하고, 색은 CSS 변수(배경·표면·글자·보조 글자·테두리·입력 배경·입력 글자·placeholder·비활성)로 정의해 `prefers-color-scheme: dark`에서 값만 바꾼다
- `input`, `select`, `textarea`, `button`의 배경·글자·테두리·placeholder·`:disabled` 색을 명시 (브라우저 기본값에 맡기지 않음)
- 진행 표시(상단 알약)도 다크 모드에서 대비 확인
- 검증: 라이트·다크 두 모드로 옵션·팝업(메인·설정) 화면을 Playwright `colorScheme`으로 캡처해 `.output/ui-*-{light,dark}.png`로 저장하고, 주요 텍스트 대비가 WCAG AA(4.5:1) 이상인지 단위 테스트나 스크립트로 확인

### B. Mac 단축키를 Control로
- `commands`의 `suggested_key`에 `mac` 항목 추가: `toggle-translate` = `MacCtrl+A`, `cycle-mode` = `MacCtrl+S` (다른 OS는 `Alt+A`, `Alt+S` 유지)
- 주의: `suggested_key`는 **새로 설치할 때만** 적용된다. 이미 설치된 확장은 기존 단축키가 유지되므로, 옵션·팝업 단축키 안내 문구에 "브라우저 단축키 설정에서 바꿀 수 있습니다"를 유지하고, 보고서에 사용자가 할 일(확장 제거 후 재설치 또는 `brave://extensions/shortcuts`에서 변경)을 적는다
- 단축키 표시 문구가 Mac에서 `⌃A`로 보이는지 확인
