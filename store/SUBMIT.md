```
웹 페이지 레이아웃을 깨지 않고, 원문 문단 아래에 AI 번역문을 붙여 주는 이중 언어 번역 확장입니다.
한 번 번역한 문단은 브라우저에 저장해 두었다가, 같은 페이지에 다시 오면 AI를 다시 부르지 않고 바로 보여 줍니다.

■ 주요 기능
• 표시 모드 3가지: 이중 언어 / 번역문만 / 원문만
• 문단 단위 캐시: 다시 방문하면 바로 복원, 페이지가 일부 바뀌면 바뀐 문단만 새로 번역
• 화면에 보이는 부분부터 번역해 API 비용 절약
• 드래그한 문장만 골라서 번역
• 용어집: 고유명사·전문 용어를 원하는 대로 고정
• 토큰 사용량 기록: 이 페이지, 오늘·7일·30일, 모델별
• 자동 번역 사이트 등록, 단축키(번역 켜기/끄기, 표시 모드 바꾸기)
• 번역 캐시 내보내기·가져오기

■ 번역 엔진
본인의 AI API 키로 번역합니다. 여러 AI 제공자 중 원하는 곳을 설정에서 고를 수 있고, 무료 키를 발급하는 제공자로도 시작할 수 있습니다.

■ 시작 방법
1. 설치 후 확장 아이콘 → 설정
2. 번역 엔진을 고르고 API 키 입력 → "키 확인"
3. 모델 선택 → "저장"
4. 번역할 페이지에서 "지금 번역"

■ 개인정보
개발자 서버가 없습니다. 번역할 문장은 사용자가 고른 AI 제공자로만 직접 전송되며, API 키와 번역 캐시는 브라우저 안에만 저장됩니다.
```
